# 小毛毛微信小程序

小毛毛的微信小程序客户端，与现有 Web 端共享内容数据。

## 本地使用

使用微信开发者工具导入 `miniprogram-project/`，配置实际 AppID 和 `config.js` 中的 API 地址后即可运行。

### 小程序邮箱注册

登录页支持切换到注册表单，注册成功后自动登录。使用现有 SMTP 配置，后端必须启用 `EMAIL_ENABLED=true`；注册需同时通过邮箱验证码和图形验证码。邮箱验证码有效期为 10 分钟，图形验证码为 30 秒，过期后点击“换一张”。小程序只读模式下注册不可用。

新增文案在管理后台「系统设置」的小程序界面映射中配置（`register*` 和 `loginSwitch` 字段）。登录页底部提示使用新的 `registerHint`，避免旧的“注册请前往网页端”配置继续显示。已有其他自定义映射保持不变。

更新时先部署后端及网页管理端，再重新编译、上传小程序。后端新增 `/api/auth/captcha?format=png` 图片输出，小程序不再直接渲染 SVG；无需数据库手工迁移，新映射键自动补齐。

本地逻辑测试：`node --test miniprogram-project/tests/registration.test.cjs`（在仓库根目录执行）。上线前使用微信开发者工具和真机检查验证码显示、邮件收取、注册及自动登录。
