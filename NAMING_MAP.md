# Mini Program Naming Map

`miniprogram-project/services/api.js` 使用以下内部简称：

| Short name | Meaning |
| --- | --- |
| `posts` | `getPosts` |
| `detail` | `getPostDetail` |
| `categories` | `getCategories` |
| `msgs` | `getComments` |
| `msg` | `createComment` |
| `post` | `createPost` |
| `image` | `uploadImage` |
| `video` | `uploadVideo` |

未列出的 API 名称保持原样。
